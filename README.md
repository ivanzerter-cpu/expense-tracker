# Трекер расходов

Мобильное приложение для учёта личных расходов: категории, отчёты за период, простая диаграмма статистики.
Учебная практика по ПМ.01 «Разработка модулей программного обеспечения для компьютерных систем».

## Стек

- Flutter (Dart), Android 8.0+
- SQLite (пакет sqflite)

## Структура репозитория

```
project/
├── README.md
├── .gitignore
├── docs/        документы по дням (day1, day2, ...)
├── src/         исходный код
├── tests/       unit-тесты
└── assets/      ресурсы приложения
```
