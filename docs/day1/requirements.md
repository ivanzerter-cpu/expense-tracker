# Анализ ТЗ. Требования

## Функциональные требования

| № | Название | Описание |
|---|---|---|
| ФТ-1 | Добавление расхода | Ввод суммы (больше 0, до 2 знаков после запятой), выбор категории и даты, необязательный комментарий. |
| ФТ-2 | Редактирование и удаление | Изменение и удаление записи о расходе; удаление только после подтверждения. |
| ФТ-3 | Список расходов | Записи отсортированы по дате (новые сверху); фильтр по периоду и по категории. |
| ФТ-4 | Категории расходов | Предустановленные категории (Продукты, Транспорт, Жильё, Развлечения, Здоровье, Прочее); добавление, переименование и удаление своих. При удалении категории её расходы переносятся в «Прочее». |
| ФТ-5 | Отчёт за период | Общая сумма расходов, сумма и доля (%) по каждой категории за выбранный период. |
| ФТ-6 | Визуализация | Простая диаграмма по результатам отчёта (круговая по категориям или столбчатая по дням). |
| ФТ-7 | Хранение данных | Данные хранятся в локальной БД SQLite и сохраняются между запусками приложения. |
| ФТ-8 | Экспорт | Выгрузка расходов за период в CSV-файл (работа с файловой системой, дни 4–5). |

## Нефункциональные требования

| № | Название | Описание |
|---|---|---|
| НФТ-1 | Платформа | Android 8.0+ (эмулятор или устройство); Flutter (Dart). |
| НФТ-2 | Автономность | Работа без интернета и без регистрации. |
| НФТ-3 | Производительность | Отклик на действия не более 1 с при 10 000 записей. |
| НФТ-4 | Надёжность | Валидация ввода, понятные сообщения об ошибках, отсутствие аварийных завершений. |
| НФТ-5 | Точность сумм | Суммы хранятся целым числом копеек, чтобы исключить ошибки округления. |
| НФТ-6 | Тестируемость | Бизнес-логика отделена от интерфейса и покрыта unit-тестами. |

## Пользовательские сценарии

| № | Сценарий | Описание |
|---|---|---|
| С-1 | Добавить расход | Пользователь открывает экран добавления, вводит сумму, выбирает категорию и дату, сохраняет; запись появляется в списке. |
| С-2 | Исправить запись | Пользователь открывает расход из списка, меняет сумму или категорию либо удаляет запись после подтверждения. |
| С-3 | Посмотреть расходы за период | Пользователь задаёт даты и/или категорию и видит отфильтрованный список с итогом. |
| С-4 | Получить отчёт | Пользователь выбирает месяц и видит общую сумму, суммы и доли по категориям и диаграмму. |
| С-5 | Управлять категориями | Пользователь добавляет свою категорию, переименовывает или удаляет её. |
| С-6 | Выгрузить данные | Пользователь экспортирует расходы за период в CSV-файл. |
