# Реестр рисков

| Риск | Вероятность | Влияние | Мера |
|---|---|---|---|
| Нехватка времени на интерфейс и диаграмму | Средняя | Высокое | Оставить одну диаграмму; интерфейс строить из стандартных виджетов Flutter. |
| Проблемы с окружением (Flutter SDK, эмулятор) | Средняя | Высокое | Проверить запуск пустого приложения на день 2; запасной вариант — реальное устройство. |
| Потеря кода и документов | Низкая | Высокое | Коммит каждый день, push в удалённый репозиторий, теги dayN. |
| Ошибки округления сумм | Средняя | Среднее | Хранить суммы целыми копейками, форматировать только при выводе. |
| Слабое знание работы с SQLite во Flutter | Средняя | Среднее | Заранее изучить sqflite и написать пробный запрос в день 3. |
| Расширение требований в ходе работы | Низкая | Среднее | Придерживаться зафиксированного scope; новые идеи вносить в список «после защиты». |
